# Contributing to Myntra Clone Frontend

Thank you for your interest in contributing to this project.

This project is a front-end demo inspired by Myntra and is intended for learning, portfolio work, and UI experimentation. Contributions that improve the shopping experience, polish the design, or expand the front-end functionality are welcome.

## How to contribute

1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Make your changes locally.
4. Test the UI in the browser to ensure it works as expected.
5. Commit your work with a clear message.
6. Open a pull request describing what you changed and why.

## Contribution guidelines

- Keep the code clean and readable.
- Match the existing styling and layout patterns.
- Prefer simple, maintainable JavaScript and CSS.
- Avoid adding unnecessary dependencies.
- Ensure the project still works as a static front-end demo.
- Test on desktop and mobile-friendly layouts where possible.

## Good contribution ideas

- Improve responsiveness
- Enhance the product filter experience
- Refine hover states and transitions
- Add more product cards and categories
- Improve accessibility and keyboard interactions
- Add better cart and wishlist behavior
- Create a more realistic checkout flow

## Pull request checklist

- [ ] The feature works locally
- [ ] Styling remains consistent with the current design
- [ ] No unrelated files were changed
- [ ] The description explains the purpose of the changes
- [ ] The app still opens correctly in a browser

## Questions or suggestions

If you want to propose a larger feature or redesign, open an issue first so the direction can be discussed before implementation.

Thank you for helping make this project better.
